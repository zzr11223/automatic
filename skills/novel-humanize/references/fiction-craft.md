# 虚构类专项（小说 / 网文 / 剧本）

> 思路参考 dbhosbu-dotcom/renwei 的虚构类覆写层与 F1-F10 规则（MIT），已按中文小说写作场景改写与扩写。

写小说改稿，和改文章是两套规则。一部分"AI 味"规则在小说里会**把好文字改坏**，必须先关掉；另一部分（长篇连贯性）则比文章更要命。

## 一、虚构类豁免与放宽（先关掉这些误伤项）

| 项目 | 文章里的规则 | 小说里的处理 |
| --- | --- | --- |
| 拟人修辞 | "自由基试图攻击细胞"是伪生动 | **豁免**。文学就是要拟人："风推开了门""夜色压下来"是笔法 |
| 细节真实性 | 案例必须有真实出处 | **豁免**。小说本来就是编的——但设定与人物逻辑必须自洽（见 F5） |
| 白描 / 渲染比 | 70% 白描 + 30% 渲染 | **放宽为 50 / 50**，允许整段渲染。硬派推理偏白描，言情古风偏渲染 |
| 信息密度 | 每段必须推进信息 | **放宽**。氛围、心理、留白都是有效内容；只清理真正的空转（同义反复、无信息的抒情堆砌） |
| 三项排比 | 严控 | **放宽约 2 倍**。排比在文学里是节奏工具 |
| 破折号 | ≤1 次/千字 | **放宽至 ≤3 次/千字**。对话中断、思绪跳转是正当用法 |
| 比喻意象域 | 全书 ≤3 个 | **放宽至 ≤5 个**，但单一场景内必须统一，不能一段里三个意象域打架 |

## 二、场景级四病（改单场戏时用）

### F1 对话同质化（最致命的破绽）
- 特征：所有角色说话像同一个人——同样的句长、同样的用词层级、同样的语气词。AI 写的不是"角色在说话"，是"叙述者分饰多角"。
- 反例：老张说："我认为这件事需要慎重考虑，我们应该先评估风险。"小李说："我同意你的观点，确实需要更全面的分析。"
- 正例：老张把烟摁灭："急什么，先看看水多深。"小李盯着表："再看下去人就跑了。"
- 改法：
  1. 给每个主要角色定 2-3 个**语言指纹**：句长偏好、口头禅、用不用成语、说话拐不拐弯（写进"人物声音卡"）。
  2. 遮住人名读一遍——认不出谁是谁，就是失败。
  3. 让角色**答非所问**。真人对话很少是标准问答对。

### F2 情绪直述而非呈现
- 特征：直接给情绪标签，而不是让读者从动作和细节里自己得出。（对应诊断清单 D4）
- 反例：她感到非常悲伤，内心充满了痛苦和失落。
- 正例：她把那件外套叠好，又拆开，再叠。第三次时手停住了。
- 改法：搜"感到 / 觉得 / 心中充满 / 内心" + 情绪词 → 改成动作、身体细节或环境。
- 例外：快节奏段落可以直述，不必每处展开——**全展开会拖垮节奏**。

### F3 万能场景开头
- 特征：开场句换个故事也能用。高频模板：阳光透过窗户洒在地板上 / 微风轻轻拂过 / 空气中弥漫着咖啡的香气 / 天空湛蓝如洗 / 街道上人来人往。
- 改法：开场第一句必须**只属于这个场景**——带上具体但不典型的物、声音、气味或不适感。
- 反向检验：把这句话搬到另一本书的另一章，还成立吗？成立就是废句。

### F4 陈腐身体反应
- 特征：情绪的身体反应只有那几套。高频：心里一紧 / 心如刀绞 / 瞳孔一缩 / 打了个寒颤 / 呼吸一滞 / 后背发凉 / 攥紧拳头 / 咬紧牙关。
- 改法：
  1. 全书同一种反应**不超过 2 次**。
  2. 换成**具体而非典型**的反应：不是"手在抖"，是"钥匙插了三次才进锁孔"。

## 三、长篇级六病（改整本/多章时用）

### F5 设定漂移（长篇核心）
- 特征：写到后面，人物和世界的设定被自己悄悄改掉。第 3 章的绿眼睛第 18 章成了褐色；说"三天后"中间写了五个日出；"魔法要付出代价"后面主角免费施法。
- 改法：
  1. 建**设定卡**：每个主要角色一张（外貌 / 年龄 / 口癖 / 关系 / 惯用手），世界规则一张。
  2. 定稿前检索逐项核对每个特征词在全书的出现处。
  3. 冲突时**保留更晚、更成熟的版本**，回改前文（或记入修改日志待用户决定）。

### F6 伏笔未回收
- 特征：前面郑重其事介绍的物件、人物、悬念，后面再没出现。
- 改法：
  1. 建**伏笔台账**：埋在第几章 / 预计第几章回收 / 是否已收。
  2. 定稿逐条对账。收不了的**回头把伏笔删掉**——比留着不收好。
  3. 反向也查：结尾突然冒出的关键道具，前文有没有铺垫。

### F7 节拍平均
- 特征：每个场景长度差不多、强度差不多，读起来像匀速传送带。不会"赶戏"也不会"停下来"。
- 改法：
  1. 高潮前**压缩**：短句、短段、少描写。
  2. 高潮后**留白**：给一个安静的场景让读者喘气。
  3. 把每章场景数和字数列出来看曲线——**一条直线就是问题**。

### F8 角色 OOC 与动机断裂
- 特征：角色做出不符合已建立性格的事，只因为情节需要。
- 改法：
  1. 每个转折问一句：**这是这个人会做的事，还是作者需要他做的事？**
  2. 必须反常时，前面要给出代价或铺垫。
  3. 检查动机链：他为什么现在做这件事，而不是三章前？

### F9 视角泄漏（POV Leak）
- 特征：限制视角里突然写出视角人物不可能知道的信息——别人的心理活动、另一个房间发生的事。
- 反例：我站在山顶。此时百里外的家中，妻子正默默为我祈祷。
- 正例：我站在山顶。这个点，她大概又在窗边坐着了。
- 改法：全书标定视角类型（第一人称 / 第三人称限制 / 全知），每章开头确认；换视角必须在**章节或分节边界**，不能段中偷换。

### F10 形容词过载的动作描写
- 特征：动作句里堆副词和形容词，动作本身反而模糊。
- 反例：他猛地、快速地、用力地将那扇沉重的木门狠狠推开。
- 正例：他一肩撞开门。
- 改法：动作句里副词**最多留一个**；优先换更准确的动词（推→撞 / 顶 / 掀），而不是给弱动词加副词。

## 四、网文补充（连载场景）

- **章末钩子**：每章结尾要有具体悬念，但**钩子款式要换**——全是"他瞳孔一缩"式等于没有钩子。检查最近 10 章钩子类型分布。
- **爽点节拍**：改稿不得拖慢爽点间隔（打脸、升级、揭示的节奏是网文生命线）。人味化 ≠ 文艺化。
- **前情回顾**：连载平台的前情回顾文字若也要改，注意与正文语气统一。
- **章长波动**：每章字数刻意微调，全部 3000±10 字反而机械。

## 五、长上下文一致性工具（整本改稿必建）

| 工具 | 内容 | 用途 |
| --- | --- | --- |
| 设定卡 | 每人一张：外貌 / 年龄 / 口癖 / 关系 / 能力边界 | 防 F5 |
| 伏笔台账 | 埋点章节 / 回收章节 / 状态 | 防 F6 |
| 数据时间线表 | 关键数字（年龄、日期、距离、金额）与时间线 | 防数值矛盾 |
| 人物声音卡 | 语言指纹：句长、口头禅、禁用词 | 防 F1 |
| 修改日志 | 每章主要改动记录 | 防改出新矛盾 |

**首尾对齐**：第一章和最后一章一起读——结尾回应了开篇的问题吗？
**承诺对账**：书里所有"后文会讲 / 这里先不提"的声明，后面兑现了吗？

## 六、交付前自检（小说版）

1. 遮住人名读对话——每个角色认得出吗？
2. 抽 5 段看形状——是不是同一个模板？
3. 所有数字、外貌、称谓列成表——对得上吗？
4. 每章结尾的钩子——款式是否重复？
5. 朗读一章——哪里卡、哪里顺得可疑？

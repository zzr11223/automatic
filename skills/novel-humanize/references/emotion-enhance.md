# 情感增强方法论

## 核心公式

**情感 = 代价 + 选择 + 延迟反应**

- **代价**：情感要有成本——时间、面子、风险、放弃的东西。没有代价的情绪只是噪音。
- **选择**：人物在情感里做的选择才动人。"他爱她"是设定，"他删掉了那条只有她能看懂的动态"才是情感。
- **延迟**：真实的人不会即时、完整地反应情绪。延迟、转移、错位才真实。当场大笑，回家路上突然停住——后者更真。

## 五种手法

### 1. 物件锚点法
用一个物件承载一段关系，三步走：**细节 → 回忆 → 动作**。
- 反例：她想起了去世的外婆，心中充满怀念。
- 正例：外婆的顶针还在她抽屉里，铜的，被磨得发亮。她每次找东西翻到它，都会把它翻个面，让磨亮的那面朝下。
- 原理：情感挂在具体的物件上，读者才摸得到。

### 2. 身体先行法
情绪先到身体（喉咙、手、呼吸、视线、脚步），再到意识。
- 反例：他感到一阵紧张。
- 正例：他发现自己在数电梯的楼层。1、2、3……数到 12 才反应过来，早就数过头了。
- 原理：身体不会撒谎；写身体反应，不写情绪名称。

### 3. 潜台词法
说 A，想 B。对话表面一层，底下一层。
- 反例： "其实我一直都很在乎你。"他说。
- 正例：
  "你那把伞，我扔了。"
  "哦。"
  "……都破了。"
  "嗯，早该扔了。"
  "嗯。"
- 原理：两个人都在说伞，谁都没说伞。

### 4. 反差法
越在乎越克制；越愤怒越平静（或反之，按人设）。
- 反例：他愤怒地大吼，眼中燃烧着怒火。
- 正例：他把碗里的面一根不剩地吃完，碗放进水槽，回屋，关门。门没摔。他老婆后来跟女儿说："你爸今天不太对。"
- 原理："门没摔"比摔门更有信息量——读者会自己去补那扇没摔的门。

### 5. 余震法
把对高潮的反应放到事后：独处时的失态、第二天的一个小动作。
- 反例：听到消息的瞬间，她泪如雨下。
- 正例：她当时很平静，还安慰了别人。晚上回到房间，她把外套挂在衣架上，挂了两遍——第二遍是因为第一遍挂反了，她没看出来。
- 原理：真正的崩溃常发生在没有人看的时候。

## 情感节奏模板

铺垫（克制，埋细节）→ 触发（小事件，不吵嚷）→ 泄露（控制不住的小动作）→ 余震（时间跳跃后的行为）

一次场景只用一个情感高点，不要句句揪心。

## 分场景实战

### 离别（亲情版）
- 反例：母亲眼中含着泪光，依依不舍地看着我，千言万语都化作一句"照顾好自己"。
- 正例：我妈把箱子的拉链头擦了一遍，说这个容易锈。检票的时候她突然说："手机壳太薄了。"我说没事。她说："太薄了。"然后从包里掏出一个新的，包装都没拆——大概早就买好了。
- 原理：不舍不在眼泪里，在"早就买好的手机壳"和那句没法反驳的"太薄了"里。

### 愤怒
- 反例：他怒不可遏，一拳砸在桌上，眼中燃烧着熊熊怒火。
- 正例：他听完，很平静地把碗里的面吃完了，一根都没剩。然后站起来，把碗放进水槽，回屋，关门。门没摔。
- 原理：极端愤怒往往表现为反常的平静，用旁观者一句"他今天不太对"侧写。

### 暗恋 / 心动
- 反例：她的心跳漏了一拍，脸上泛起红晕，一种莫名的情愫在心中滋生。
- 正例：他上台的时候，她本来在跟同桌说话。同桌问"然后呢"，她说"啊？"。同桌翻了个白眼。
- 原理：心动的证据是"注意力失守"——话断了、答非所问、突然听不见。

### 愧疚
- 反例：他的内心充满了深深的愧疚与自责，泪水模糊了双眼。
- 正例：晚上他给他妈打电话，响了两声就挂了，改成发微信："最近挺好的。"他妈秒回："嗯，钱够不够。"他盯着这五个字看了一会儿，把手机扣在桌上。
- 原理：愧疚让人不敢直接联系；母亲的"秒回"和"钱够不够"暴露了她一直在等——双方都在藏。

### 亲情（写父母）
- 反例：父亲的爱是深沉的，他默默地为我付出了一切，却从不言说。
- 正例：我爸从来不说想我。他的方式是每周三发一张他做的菜。有一次我回"看着不错"，他第二天就坐高铁来了，带了那个菜。
- 原理：不说爱的父爱，用仪式（每周三）和行动（带着菜坐高铁）来写。

### 死亡 / 失去
- 反例：噩耗传来，她几乎崩溃，泪水决堤而下，整个世界都崩塌了。
- 正例：她把他的拖鞋收进柜子，收的时候是倒着放的，鞋尖朝里——这个习惯是他教的，说这样落灰少。收完她愣了一下，又把拖鞋拿出来，放回门口。
- 原理：失去里最柔软的一处是"习惯还活着"；收起来又放回去，比"崩溃"更疼。

## 伪情感清除清单

- 替读者感动：作者跳出来抒情、总结、升华
- 形容词叠罗汉：无尽的悲伤、深深的绝望、难以言喻的痛苦
- 全员大情绪：每个在场角色都在狂悲狂喜
- 情绪没有来源：没有铺垫就哭/就笑/就爆发
- 三件套滥用：眼泪 + 大喊 + 下雨
- 用力过猛：每段都"撕心裂肺" = 读者麻木

## 情感浓度自检 5 问

1. 读者能不能说出人物具体在意的东西/物件？
2. 这份情感有代价吗？人物失去了什么？
3. 反应有延迟或错位吗，还是标准反应？
4. 有没有一个物件参与叙事？
5. 把所有情绪形容词删掉，还剩得下情感吗？

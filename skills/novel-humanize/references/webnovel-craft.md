# 网文（爽文）修订专项

> 规则综合自 zenstory-ai/oh-story-claudecode（story-deslop / story-review，MIT）与 QIUZHIYI1352/webnovel-writer，已按本 skill 场景改写。
> 适用：改稿对象是中文网络小说（番茄 / 起点 / 七猫 / 知乎盐言等）时，本文件与 `fiction-craft.md` 一起用；本文件管"爽文特有问题"，`fiction-craft.md` 管"小说通用问题"。

## 一、修订五守则（先立规矩，再动笔）

1. **改最少，效果最大**：能改一个词就不改一句，能删一句就不重写一段；人名、地名、数字、章节名、专有名词优先保留；没有问题的句子尽量保留原句。去 AI 味是改味，不是重写。
2. **删除比例上限**（按 AI 味档位）：轻度 **≤15%** / 中度 **≤25%** / 重度 **≤35%**。**不得整段删除正文**——多处 AI 味的段落要逐句修改，而不是删掉。
3. **删除前九问**（任一命中就不删，改"降 AI 重写"）：伏笔 / 钩子 / 角色特征 / 情节推进 / 人物记忆 / 情绪承接 / 因果锚点 / 收益兑现 / 爽点铺垫。
4. **存疑不删**：疑似 AI 味但拿不准的，标 `[需复核]` 保留，交作者定夺，而不是替作者做决定。
5. **只改"怎么说"，不改"说什么"**：剧情、人设、走向一概不动；发现的逻辑问题单独标记，不借润色顺手改剧情。

## 二、收益节奏（改稿红线：读者的耐心是有账期的）

| 指标 | 标准 |
| --- | --- |
| 前 3 章 | 兑现（爽 / 燃 / 打脸 / 升级）≥ 1 次 |
| 前 10 章 | 兑现 ≥ 2 次、收益 ≥ 3 次 |
| 连续"只有成本、没有收益" | ≤ 2 章 |
| 两次兑现之间空档 | ≤ 8 章 |
| 软钩（纯留白 / 悬停式）占比 | ≤ 60%（钩子不能全是"欲知后事"） |

- **爽点释放原则**：铺垫要充分、释放要干脆。**改稿只许让爽点更密、更快，不许变疏、变慢。**
- 每 3000-5000 字至少一个情绪节点（笑点 / 爽点 / 燃点 / 泪点）；改稿时删描述可以，**删"回报"是事故**。
- 改战斗章时特别注意：水词可以删，但"我方得手 → 敌方反应 → 我方从容"的节奏链不能压掉——压缩的是修饰，不是打击感。

## 三、自然网文基准（量化尺子：判"改不够"也判"改过头"）

### 句长（爆款语料校准，长篇现言/都市/古言/玄幻/历史 125 本统计）
- **叙述默认写逗号长句**：逗号之间 **8-12 字**、整句 **20-30 字**，一句用逗号串 2-4 个动作或信息，再落句号。
- 逗号长句占叙述句 **74-80%**；≤5 字的短片段约占 **两成**（多是重拍、转折、时间词）。
- **短句是工具，不是默认**：全篇碎句、句号密得像提纲（电报体），与 AI 腔是同一级别的问题——"拆短"不是去 AI 味的方向，改对节奏才是。
- 对话：口语化，长短随角色，不统一整形。

### 段落与节奏
- 段落随 beat 长短不一：爽点 / 转折压短，推理 / 氛围 / 情绪链放长。番茄样本段落中位约 **23 字**；对话占比约 **20%**（顺其自然，不硬凑比例）。
- 弱化副词（微微 / 淡淡 / 缓缓 / 轻轻）≤ **3 个/千字**。
- 章尾：动作 / 对话 / 悬念收束；**禁止**总结、升华、预告（"他不知道的是……"）。

## 四、毒点排查（修爽文时逐项过——这是读者真正掉头走的地方）

**结构毒点（优先修）**
- 主角吃亏没有回报；连续压而不兑现
- 升级 / 打脸间隔被拉长（改稿把爽点改疏了）
- 钩子同款连用 ≥5 章；开头同质化（能整体换到任意同类书）
- 信息倾倒：让角色直接开口解释世界观 / 规则

**人物毒点**
- 圣母、舔狗、降智、无脑原谅；反派降智（赢了没意义）
- 关系越界无铺垫：突然信任、突然亲密、突然敌对
- 动机断裂：为剧情服务牺牲人设

**表达毒点**
- 说明书式对话（对话在交换资料，不在交锋）
- 上帝视角剧透（殊不知 / 多年以后 / 冥冥之中 / 仿佛预示着）
- 解释腔把话说满（他终于明白 / 这意味着 / 正是因为）

**一致性问题（S1 级）**：设定冲突、时间线矛盾、称谓漂移——发现即列为最高优先级，单独出核对清单。

## 五、改后检查清单（逐条过）

- [ ] **剧情功能核对**：伏笔 / 钩子 / 角色特征 / 因果锚点完好；删除比例未超档
- [ ] **句长基准**：逗号间 8-12 字、整句 20-30 字为主；没有碎句成片的段落
- [ ] 高频词扫描通过；弱化副词 ≤3 个/千字
- [ ] 章尾无总结 / 升华 / 预告
- [ ] 对话口语化、角色语气可区分、无说明书腔
- [ ] Show, don't tell；无解释腔、无上帝视角
- [ ] **退化自查**：无逐字复读、无截断、无占位符、**工程词不泄漏**（"细纲""情节点""大纲""人物弧光"等词不得出现在正文里）
- [ ] 不做投机：不为反检测强制换行、不硬凑对话占比、不把省略号改成英文点、不乱改的地/得

## 六、平台口味速查与报告口径

| 平台 | 口味 |
| --- | --- |
| 番茄 | 强开局、强冲突、高频情绪反馈、低理解门槛（手机端短段） |
| 起点 | 设定自洽、升级路径清晰、长线期待、世界观承载力 |
| 知乎盐言 | 短篇钩子、反转密度、信息差推进 |

报告严重度口径（与诊断报告模板配合使用）：
- **S1 必改**：破坏主线 / 人设 / 世界规则 / 读者信任
- **S2 本轮要修**：明显影响章节效果、留存、节奏、人物可信度
- **S3 建议改**：局部措辞、轻微格式、局部节奏
- **S4 可不动**：风格微调，不阻塞发布

# 人味化手法库

使用说明：每招给出「反例」（典型 AI 味）与「正例」（改写后），并附一句原理解释。改写时**先从减法开始**（第一部分），修欧化句式（第十一节），再按需叠加其余手法。

---

## 第〇部分：改稿前置——保真五原则（先读，违反任何一条都算改坏）

1. **不加事实**：不添加原文没有的人名、数字、日期、经历、引文。需要细节但没有时，写更简单的句子，或问用户。
2. **不丢信息**：删改必须有理由——空泛、重复、歧义、不合文体。真实的判断、立场、限定、归因不能以"去痕迹"为由删掉。
3. **不改变确定程度**：不把"可能"改成"确定"，不把"相关"改成"因果"，不把"计划"改成"已完成"，不把"部分"改成"全部"。
4. **虚构豁免**：小说里细节可以编（那本来就是创作），但设定、人物逻辑、已发生的情节不能漂移。
5. **改最少，效果最大**：能改一个词就不改一句，能删一句就不重写一段；删除比例上限——轻度 ≤15% / 中度 ≤25% / 重度 ≤35%（按诊断档位）；不得整段删除正文；拿不准的标 `[需复核]` 保留。删除前先过九问：伏笔 / 钩子 / 角色特征 / 情节推进 / 人物记忆 / 情绪承接 / 因果锚点 / 收益兑现 / 爽点铺垫，命中任一即改用"降 AI 重写"。

> 一句话：去 AI 味是"换个说法"，不是"换个意思"，也不是"把书删掉一半"。

---

## 一、减法七刀（优先执行，改稿顺序也是这个顺序）

1. **删升华句**：段落末尾的抒情 / 总结全部删掉。
   - 反例：……他转身离开。这一刻，他终于明白，有些路只能一个人走。
   - 正例：……他转身离开。公交卡在口袋里硌着手，他掏出来，又放回去。
2. **删解释**：删"因为……所以""这让他意识到""原来"。
3. **删过渡**：删"就这样""与此同时""时间一晃""不知过了多久"。
4. **删万能词**：不禁 / 缓缓 / 轻轻 / 淡淡……全删一遍，再回填不到 5%。
5. **删排比**：三个并列砍到一个；剩下的那个才有分量。
6. **删副词标签**："愤怒地说"→ 换成动作或直接删。
7. **删段尾总结句**：段落最后一句如果是作者替读者做的总结，删。

## 二、抽象沉降（具体化）

反例：她心里藏着深深的委屈。
正例：她把外卖评价从五星改成四星，又改回五星，最后把评价删了。
原理：委屈 = 有火没处发，只能跟一个无关的东西较劲。

反例：他老家的房子很破旧。
正例：他老家门框上刻着他的身高，最深的一道是 1 米 43，初二那年。之后门框再没动过。
原理：用"时间的物证"替代形容词。

操作三问：这个情绪 / 状态，会让他做出什么**具体的、小的、带数字的**行动？

## 三、情绪外化

步骤：① 圈出所有情绪词；② 问"这个情绪的痕迹会留在哪里"（身体 / 动作 / 物件 / 环境）；③ 只写痕迹。
- 反例：她心里很难过，却强装笑颜。
- 正例：她洗碗洗了四十分钟。水早就凉了。
要点：痕迹要小、要具体、要符合人设。详细方法见 `emotion-enhance.md`。

## 四、节奏手术

1. **长短交替**：连续三句 15 字以上之后，插一个 3-5 字短句。
2. **单句成段**：情绪重击处独立成段。
3. **慎用破折号与省略号**（AI 爱用）；用句号断开更狠。破折号参考线：≤3 次/千字（小说档）。
- 反例：他的拳头重重地砸在墙上，鲜血顺着指缝流下，他却仿佛感觉不到疼痛。
- 正例：他一拳砸在墙上。血从指缝里渗出来。他没觉得疼。或者说，顾不上。

## 五、对话活化

1. 删"说道 + 副词"，改用动作插入。
2. 加打断与抢话。
3. 答非所问、转移话题。
4. 每个角色一个口头禅 / 称呼习惯（写进人物声音卡）。
5. 沉默也算一句台词。
- 反例："我很担心你。"他皱着眉头说道，语气中带着一丝不安。
- 正例：
  "你吃了吗。"
  "嗯。"
  "……嗯是什么意思。"
  "就是嗯。"
- 原理：对话不是交换信息，是互相试探、掩饰、较劲。

## 六、比喻重建

原则：① 从人物经验域取材；② 跨域要远；③ 宁可粗糙不要圆滑；④ 密度控制——一章 2-3 个优质比喻足够；⑤ 单一场景内意象域统一（全书 ≤5 个域）。
- 反例：他的心像被刀割一样疼。
- 正例（屠夫的儿子）：这感觉他熟，像小时候看他爹杀猪，刀没扎准地方，血在皮下攒出一个包，鼓着，下不去。
- 原理：比喻的价值在"只有这个人才会这么想"。

## 七、不完美注入（人味主要来源）

- **冗余动作**：进门先放钥匙、坐下前擦一下椅子（与剧情无关但真实）。
- **小失误**：说错话马上改口、走错路、叫错名字、话说到一半忘了词。
- **无意义细节**：三个字的地名、具体时刻、便宜的小物件。
- **允许没用的对话**：真实聊天里一半是废话。
- 注意：不完美要符合人设，且不能破坏关键情节逻辑。

## 八、视角收敛

- 反例：她不知道，这一幕被角落里的黑衣人看在眼里。
- 正例：角落里烟头亮了一下，又灭了。
- 反例：其实他早就知道了。
- 正例：（删掉，让后面的行为自己表演）
- 原理：读者"自己发现"的信息，比作者"告知"的信息动人十倍。

## 九、五感改造

优先级：气味 > 触感 / 温度 > 听觉 > 非常规视觉细节。
- 反例：她看起来很苍白。
- 正例：她嘴唇起皮了，说话时舌尖一直去舔那个裂口。
- 原理："苍白"是判断，"舔裂口"是观察。读者信观察，不信判断。

## 十、用词降级与题材校准

- 书面词 → 生活词：凝视 → 盯着；离去 → 走了；顿时明白 →"哦"了一声。
- 四字词堆砌 → 拆成一句大白话。
- 古风：不能出现现代词，但也不必全篇文言腔——口语感来自句式，不来自词汇。
- 都市：允许不完整句、流行语（按人设与平台）。
- 网文：爽点节奏、章末钩子结构不能因改稿而变慢。

## 十一、欧化中文修复（逐句手术）

AI 写中文最底层的病是英文思维硬套中文句法。以下是最常见的六种：

### 1. "的"字长定语链
- 反例：这是一个关于如何在不牺牲可读性的前提下提升系统高并发处理能力的讨论。
- 正例：讨论的核心：怎么在保证可读性的同时，提高系统并发能力？
- 铁律：一句话"的"不超过 3 个，一条定语不超过 15 字。超了就拆成短句。

### 2. "被"字句堆叠
- 反例：这个新功能被用户们所广泛接受，并且被开发者们所推荐。
- 正例：这项新功能广受好评，开发者也大力推荐。
- 改法：能用主动就用主动；正面语境用"受 / 获 / 得到"；无主语句是地道中文（"门开了"优于"门被打开了"）。

### 3. 形式动词（进行 / 作出 / 给予 + 名词）
- 反例：专家组对方案进行了认真的讨论，并作出了评估。
- 正例：专家组认真讨论并评估了方案。
- 改法：把"进行 / 作出 + X"还原为真动词——"进行讨论"→"讨论"，"作出决定"→"决定"。

### 4. "通过……使……"双框架
- 反例：通过采用新的管理架构，使得沟通效率得到了显著提高。
- 正例：采用新架构后，沟通效率显著提高。
- 改法："通过"与"使"同现时删掉其一，优先保留真正的主语。

### 5. 代词密度过高
- 反例：她不是不懂，她懂得比谁都多。她只是累了。
- 正例：不是不懂，懂得比谁都多。只是累了。
- 改法：主语明确后后续句省略代词；连续同代词开头不超过 2 句。

### 6. 冗余时间 / 介词框架
- 反例：当他在山顶看到那片星空的时候，他受到了震撼。/ 作者通过使用大量比喻来增强感染力。
- 正例：在山顶看到那片星空时，他愣住了。/ 作者用大量比喻增强感染力。
- 改法："当……的时候"→ 删"当"或"的时候"；"在……方面"→ 删"方面"。

### 附：三个快速语病检查
- **句式杂糅**："之所以……是因为……的原因"、"本着……为原则"、"并非是"。
- **同义叠加**："大约……左右"、"亲眼目睹"、"第一部处女作"——保留一个。
- **一逗到底**：一个完整意思表达完必须用句号。整段只有逗号是 AI 重灾区。

## 十二、手动扫描命令（不用脚本时的 grep 速查）

在稿件目录里（Git Bash / 编辑器正则搜索均可）：

```bash
grep -n '不是[^，。]*而是' 稿件.md      # 不是X而是Y
grep -n '——' 稿件.md                    # 破折号，配合字数算密度
grep -n '进行\|作出\|给予\|加以' 稿件.md # 形式动词
grep -n '的[^，。；]*的[^，。；]*的' 稿件.md  # "的"字链
grep -n '通过.*使\|经过.*使' 稿件.md     # 双框架
grep -n '值得注意\|总而言之\|综上所述\|与此同时' 稿件.md  # 议论文腔
grep -n '仿佛\|如同\|宛如\|好像' 稿件.md # 比喻词密度
```

## 改写幅度分级

| 档 | 动作范围 | 句级改动率 | 效果 |
| --- | --- | --- | --- |
| A 轻润 | 删词、换词、删句 | 10-20% | 去掉表症，读感回升 |
| B 中改 | 重写句子与段落局部，保结构 | 30-50% | 人味明显，可作为常规发布稿 |
| C 深改 | 重排场景细节与信息释放顺序（不动情节结果） | 50% 以上 | 脱胎换骨，接近人类手写 |

## 收尾提醒

改完必做四件事：① 重跑扫描脚本（模型自己会引入新的统计习惯——常见的是改完破折号超标）；② 反向复扫 AI 味清单；③ 保真核对（数字 / 时间 / 称谓 / 因果 / 限定语有没有漂移）；④ 朗读一段找磕绊。

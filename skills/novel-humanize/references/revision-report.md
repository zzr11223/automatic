# 诊断报告与修改方案模板

## 一、报告结构（标准流程用）

```
# 《作品名》AI 味诊断报告

## 1. 总览
- 文本范围：第 X 章 / 全文（约 X 字）
- AI 味指数：XX / 175（中度）  →  一句话结论（附 1-2 处最强证据）
- 最主要问题：D4 情绪直述、D5 万能副词、D7 升华收尾

## 2. 评分表
| 维度 | 得分 | 权重 | 主要证据（位置） |
| --- | --- | --- | --- |
| D1 句式模板化 | 3/5 | 2 | 第 2 段"既……又……" |
| ... | | | |

## 3. 问题条目表（可截断为 Top 10，按严重度排序）
| # | 位置 | 原文（节选） | 问题标签 | 严重度 | 修改方向 |
| --- | --- | --- | --- | --- | --- |
| 1 | 第 1 段末 | "这一刻，他终于明白……" | D7 升华收尾 | ★★★ | 直接删除，在上一句动作处收束 |

## 4. 修改方案（三档，供选择）
| 档位 | 做什么 | 句级改动率 | 预计效果 | 风险 | 适合 |
| --- | --- | --- | --- | --- | --- |
| A 轻润 | 删词/换词/删句 | 10-20% | 去掉表症 | 几乎为零 | 只想过稿 / 保留原貌 |
| B 中改 | 重写句子段落局部，情绪外化、对话活化、节奏手术 | 30-50% | 人味明显 | 需校对一致性 | 常规发布稿（默认推荐） |
| C 深改 | 全维度重写 + 细节注入 + 场景重排（不动情节） | 50%+ | 接近人类手写 | 改动大，需确认保真 | 重点章节 / 参赛稿 |

## 5. 示范改写（1-3 段，见下方范例格式）

## 6. 执行计划
- 分批：按章 / 每批约 3000 字
- 交付：outputs/02-第XX章-改后.md（净稿 + 章末修改摘要）
- 里程碑：先交 1 章确认风格 → 再批量
```

## 二、轻量模式速诊表（短片段用）

只给 3-5 行，不写长报告：

| 位置 | 问题 | 改法 |
| --- | --- | --- |
| 第 2 句 | "心中五味杂陈"情绪直述 | 换成具体动作 / 物件 |
| 第 4 句 | "如同白驹过隙"比喻模板 | 直接删，保留后面的具体回忆 |
| 末句 | 升华收尾 | 删掉，在上一句动作处结束 |

## 三、报告用语规范

- 对事不对人，给理由，不嘲讽。
- 引用原文要能定位（章节 / 段落 / 原句），方便用户核对。
- 修改方向要可执行："把'心中五味杂陈'替换为一个具体动作（如把杯子放回桌上又拿起）"，不要只写"改得更自然"。
- 每批改写交付时附"本批修改点摘要"（3-5 行），让用户能追溯。
- **克制**：报告是为了让用户看见问题和改法，不是展示工作量。不堆砌术语，不为了凑数编造"无中生有"的问题。没有问题的段落，明说"这段可以不动"。

## 四、完整范例（三个题材）

### 范例一：都市情感（离别场景）

**原文（AI 味）**
> 雨淅淅沥沥地下着，仿佛在诉说着离别的悲伤。林晚站在月台上，心中五味杂陈。三年的时光如同白驹过隙，那些回忆如同潮水般涌上心头，让她不禁红了眼眶。火车缓缓进站，她深吸一口气，努力让自己平静下来。这一刻，她明白了，有些人注定只是生命中的过客。她轻轻地挥了挥手，转身离去。

**诊断**：D5 万能副词（缓缓 / 轻轻地 / 不禁）★、D4 情绪直述（五味杂陈 / 红了眼眶）★、D6 比喻模板（诉说悲伤 / 潮水般涌上心头）★、D7 升华收尾（这一刻她明白 + 过客句）★、D8 氛围套话（雨 + 离别）★、D11 细节泛化（三年时光 / 有些回忆）。

**改写（人味）**
> 月台上风很大。林晚把围巾往上拉了拉，盖住半张脸。
> 广播报站的时候她才发现，自己把票攥得皱了边。
> 他隔着一米站着，想说什么，最后只是问："那边冷吗。"
> "不知道。"她说，"还没去呢。"
> 两个人一起笑了一下，又立刻停住。
> 车来了。她上车，找到座位，把行李放好，才想起来忘了跟他挥手。她把手贴在玻璃上。
> 他好像没看见。他正在低头看手机——手机的屏幕是黑的。

**改法说明**
- 删光全部情绪词与升华句；把"不舍"翻译成动作链：拉围巾、攥皱票、答非所问的笑、"忘了挥手"。
- 结尾"黑屏的手机"是余震：读者自己明白他在假装看手机——信息由读者发现，而非作者告知。
- 全篇没有出现一个"悲伤"，但比原稿更重。

### 范例二：古风玄幻（强者归来）

**原文（AI 味）**
> 他缓缓睁开眼睛，一股强大的气势从他身上爆发而出，仿佛一头苏醒的远古凶兽。众人不禁纷纷后退，脸上露出震惊之色。这一刻，所有人都明白，他回来了。

**改写（人味）**
> 他睁眼的时候，房梁上的灰落了下来。
> 前排有人退了一步，又站稳。二叔的手按在刀柄上，按了半天，没拔。没人说话。
> 锅里的水还在响。

**改法说明**
- "气势"→ 环境反应（落灰、退步、按刀未拔）；删掉"众人震惊"的集体情绪标签，换成一个人的具体反应。
- "按了半天，没拔"自带信息量（犹豫 / 忌惮），胜过任何形容词。
- 删收尾口号，用"锅里的水还在响"收——水在响，说明所有人都不敢动。

### 范例三：悬疑（章末钩子）

**原文（AI 味）**
> 走廊里寂静无声，空气中弥漫着一股诡异的气息。她的心跳加速，不禁感到一阵莫名的恐惧。直觉告诉她，房间里有什么不对劲。她缓缓推开门——眼前的一幕让她彻底惊呆了。

**改写（人味）**
> 走廊的声控灯坏了，她只能贴着墙走。
> 左手边第三扇门底下有光。现在是凌晨两点，招待所三楼没有人住。
> 她数着自己的脚步走到门边。里面有电视的声音，开得很小，像谁把音量调到了 2。
> 她抬手敲门。电视声停了。
> "谁呀。"是个小孩的声音。
> 招待所三楼，登记簿上只住了她一个人。

**改法说明**
- 删"诡异气息 / 莫名的恐惧 / 直觉告诉她"；恐怖来自事实的排列：坏灯、黑房间却有光、凌晨两点、登记簿。
- 章尾不用"彻底惊呆了"预告，把一个反常事实（小孩的声音）放在最后——悬念由读者自己装到心里。
- 情绪不写"恐惧"，写"数着脚步"（给自己壮胆）这个动作。

## 五、保真核对（交付前必做，逐条过）

| 检查项 | 通过标准 |
| --- | --- |
| 数字 | 数字（年龄 / 金额 / 日期 / 距离）与原文一致 |
| 时间线 | 事件顺序、时长、"三天后"之类的间隔没有变化 |
| 称谓关系 | 人物称谓、关系、代号没有漂移 |
| 因果 | 没有把"相关"改成"因果"、把"可能"改成"确定" |
| 限定语 | "部分 / 所有 / 只有 / 至少"等范围词含义保留 |
| 否定 | "不是 / 没有 / 拒绝"没有被改写反 |
| 负例保真 | 明显是人写的段落，改后与原文相似度应保持 90% 以上（改坏 = 事故） |
| 统计复查 | 重跑扫描脚本：破折号、排比等指标没有因改写而超标（模型通病） |

任何一条不通过 → 回退相关句子，不放行。

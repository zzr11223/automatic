# AI 味诊断清单（16 维 + 量化阈值）

> 规则来源：Wikipedia《Signs of AI writing》、blader/humanizer、op7418/Humanizer-zh、hardikpandya/stop-slop、dbhosbu-dotcom/renwei。详见 SKILL.md 末尾"参考来源"。

## 使用方式

1. 短文本（<3000 字）：逐维快速标注，只记"命中项 + 原文证据"。
2. 长文本 / 整本：先跑 `scripts/scan_ai_flavor.py <章节目录> --csv report.csv`（词表 + 结构模式 + 量化指标，输出逐章汇总），按结果排优先级，再逐维人工诊断。
3. 每维 0-5 打分，乘以权重，汇总为启发式"AI 味指数"。
4. **无证据不下结论**：每条判断必须能指出位置和原文引用。

## 信号强度（怎么下判断，先读这一节）

同样的词，出现一次和出现二十次是两回事。判断按信号强度分级：

- **强信号**：谨慎的写作者几乎不会这么写。出现一次即可列入修改。"五味杂陈""这一刻他终于明白""空气中弥漫着"属此类。
- **中级信号**：单个可以接受；同段/同页重复，或与其他痕迹共现时处理。
- **弱信号**：必须靠密度和共现判断（"轻轻""仿佛""其实"）。孤立一处不要动。
- **共现原则**：同一段里出现多个痕迹 → 基本可判定。只有在"多个痕迹同时出现"时才下重手，这是安全线。
- **不动清单**：引文、标题、专有名词、"讨论某个词"而非"使用某个词"的地方，一律不动。2022 年之前的文本不适用本清单。

| 权重 | 维度 |
| --- | --- |
| 权重 3 | D3 抽象泛滥、D4 情绪直述、D5 万能副词、D7 升华收尾、D11 细节泛化 |
| 权重 2 | D1 句式模板、D2 节奏均匀、D6 比喻同质、D8 氛围套话、D9 解释性叙述、D10 对话书面腔、D13 逻辑过顺、D15 欧化中文、D16 段落章节模板化 |

分级只是沟通工具，不要机械报分数——要让用户看见"问题在哪、为什么、怎么改"。

## 十六个维度

### D1 句式模板化（权重 2｜中级）
- 典型：不仅……更是……、不是……而是……、既……又……、在……的同时、让……让……、排比成瘾。
- 反例：他不是不想解释，而是不知道从何说起。/ 她的眼神里既有倔强，又有脆弱。
- 改写方向：拆开，一句只留一个信息，或改成动作。→"他张了张嘴，没解释。"/"她没低头。"
- 判断要点：单个关联词不算问题，**密度**是问题。

### D2 节奏均匀（权重 2｜弱级，靠统计）
- 典型：句长集中在同一区间、段落等长、标点模式重复、每段固定 3-4 句。
- 量化线索：句长波动 CV < 0.55 偏可疑（人写文本常 > 0.7）；连续 3 句超 35 字必拆。
- **反向也查**：句均 <15 字、碎句成片 = 电报体，与 AI 腔同级的问题（自然基准：逗号之间 8-12 字、整句 20-30 字，逗号长句为主体）。
- 改写方向：以逗号长句为默认、长短有致；重击处单句成段。

### D3 抽象泛滥（权重 3｜中级）
- 典型：某种、一种……的感觉、内心深处、情感的涟漪、羁绊、宿命、气息、意义、价值。
- 反例：她心里藏着深深的委屈。
- 改写方向：抽象词是作者偷懒的地方。替换为一个具体的、小的、带数字的动作或物件。

### D4 情绪直述（权重 3｜强级）
- 典型：他感到……、心中涌起……、五味杂陈、难以言喻、复杂、莫名的、难以形容的悲伤。
- 检验法：把情绪词全删，如果读者还能从行为里读出情绪，就说明删对了。
- 改写方向：只留行为、身体反应、物件。

### D5 万能副词（权重 3｜弱级，靠密度）
- 典型：不禁、不由得、下意识、缓缓、轻轻、淡淡、微微、静静地、默默地、深深地、渐渐、顿时、瞬间、悄然。
- 改写方向：全删一遍，只放回有节奏功能的个别词（不超过 5%）。"缓缓"用在反派放慢刀子的地方才叫用对了。

### D6 比喻同质（权重 2｜中级）
- 典型：受伤的野兽、坠入深渊、断线的风筝、潮水、刀割、雷击、整个世界都安静了。
- 改写方向：从人物身份 / 职业 / 经历里取喻（屠夫用刀、医生用病历、玩家用游戏）。宁可粗糙，不要通用。

### D7 升华收尾（权重 3｜强级）
- 典型：这一刻他终于明白……、仿佛整个世界……、也许这就是……的意义、命运的齿轮开始转动。
- 改写方向：删。章节结尾用具体动作 / 物件收束，或干脆提前结束（留白）。

### D8 氛围套话（权重 2｜强级）
- 典型：空气中弥漫着……的气息、剑拔弩张、落针可闻、鸦雀无声、死一般的寂静、诡异的氛围。
- 改写方向：换成具体反常细节——哪盏灯坏了、什么声音停了、什么味道不对。

### D9 解释性叙述（权重 2｜中级）
- 典型：这让他意识到、这意味着、原来……、其实……、因为……所以……（连接词满格）。
- 改写方向：删掉解释与连接，把因果交给事件排列本身。让读者自己得结论。

### D10 对话书面腔（权重 2｜中级）
- 典型：每句都是完整句、礼貌、信息齐全、无打断、无口头禅；"……"他淡淡地说道；所有角色一个腔调。
- 改写方向：删"说道 + 副词"，换成动作插入；加打断、停顿、答非所问、沉默。
- 判断要点：真实对话的功能是试探 / 掩饰 / 较劲，不是交换信息。遮住人名读一遍——认不出谁是谁就是失败。（详见 `fiction-craft.md` F1）

### D11 细节泛化（权重 3｜中级）
- 典型：房间很简陋、眼神复杂、心跳加速、三年的时光、很多回忆。
- 改写方向：给一个具体物证——什么颜色、几块钱、什么牌子、什么味道、几点几分。

### D12 感官单一（权重 1｜弱级）
- 典型：全是视觉描写；没有气味、触感、温度、听觉。
- 改写方向：每个场次至少补 1 处非视觉感官，优先气味与触感。

### D13 逻辑过顺（权重 2｜弱级，需通读）
- 典型：每个细节都有用、每句话都推进剧情、人物不犯错不跑题、全程无冗余。
- 改写方向：注入"无用"细节与真实小失误（走错路、说错话、忘记一件事）——但必须符合人设，且不破坏关键情节逻辑。

### D14 视角漂移（权重 1｜强级）
- 典型：限制视角里突然写出视角人物不可能知道的信息；"她不知道，这一幕……"式全知提示；替读者总结。
- 改写方向：全书标定视角类型，每章开头确认；换视角必须在章节或分节边界。删越界心理描写。（长篇专项见 `fiction-craft.md` F9）

### D15 欧化中文句式（权重 2｜中级）
- 典型："的"字长定语链（一句话"的"≥3）；被字句堆叠；形式动词（进行 / 作出 / 给予 + 名词）；"通过……使……"双框架；连续句首同代词；"当……的时候""在……方面"冗余框架。
- 反例：他对这个问题进行了深入的思考。/ 通过引入新系统，使得效率得到了显著提升。
- 正例：他想了想这个问题。/ 引入新系统后，效率明显提升。
- 判断要点：这几种结构读起来像翻译稿。人写中文靠短句、意合、省略主语。修复手法见 `humanize-techniques.md` 第十一节。

### D16 段落章节模板化（权重 2｜弱级，需通读）
- 典型：每段都是"总-分-总"；段落长度雷同；每章场景数与强度均匀（节拍平均）；章尾钩子同一款式。
- 判断：抽 5 段看形状是否雷同；把每章场景的字数列成曲线——一条直线就是问题。
- 改写方向：段落形状打散；高潮前压缩、高潮后留白；钩子换款式。（详见 `fiction-craft.md` F7）

## 量化阈值参考（小说档）

以下为启发式参考线（源自 人味 renwei 与 oh-story-claudecode 的阈值，已换算为千字密度），**不是判决线**：

| 指标 | 参考线 | 说明 |
| --- | --- | --- |
| 破折号"——" | ≤3 次/千字 | 对话中断、思绪跳转是正当用法；明显超量多为翻译腔 |
| "不是X，而是Y" | >1 次/千字 需清理 | 优先清理连续两段都出现的 |
| 三项排比 | ≤10% 句子 | 让三项排比成为亮点而非常态 |
| 一句话"的"≥3 个 | 极少出现 | 长定语拆成短句 |
| 连续 3 句 >35 字 | 0-2 处 | 必拆，插短句 |
| 连续 3 句同代词开头（他/她/我） | ≤2 处 | 中文可省略主语 |
| 感叹号 / 问号 | 明显偏少需留意 | AI 对话普遍缺情绪标点；结合人设判断 |
| 句均字数 | 20-30 字 | <15 疑似电报体，>32 偏长（爆款语料整句均 22-24） |
| 短句占比（≤5 字） | ≤40% | 约两成是正常重拍；成片即电报体 |
| 弱化副词（微/淡/缓/轻） | ≤3 个/千字 | 独立计数，超出即 AI 签名 |
| 改稿删除比例 | 轻/中/重 ≤15/25/35% | 超过档位上限要回看；不得整段删正文 |

## 快速扫描（3 分钟版）

1. 跑扫描脚本 → 看词表密度与结构模式指标是否越线。
2. 看每段首尾句：若大多是总结句 / 抒情句 → 重灾区。
3. 朗读一段：顺到毫无阻力、没有想停下来的地方 → 可疑。

## 避免误伤（重要）

- 判定看三点：**密度、均匀度、是否承担叙事功能**。
- 作者刻意的口头禅、方言、重复修辞 = 风格指纹，不要当 AI 味删掉。
- **拟人在小说里是笔法，不是缺陷**："风推开了门""夜色压下来"必须留住；只清理叙述者腔调层面的滥用。
- 题材差异：古风偏书面语是风格，判断标准是"是否模板化"，不是"是否华丽"。
- 人类写作也在吸收 AI 习惯——**多个痕迹共现才是安全判据**，孤立一处不要动。
